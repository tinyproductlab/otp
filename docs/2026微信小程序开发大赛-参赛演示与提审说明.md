# 小产品实验室 OTP｜2026 微信小程序开发大赛参赛演示与提审说明

> **参赛定位：** 小产品实验室 OTP 是本地优先的验证码与密码管理小程序。验证码、密码、备份口令和 WebDAV 凭据均在设备本地处理；产品以本地规则和可解释的安全引导，帮助用户完成“发现风险—理解风险—采取行动—完成备份”的闭环。

## 一、演示目标

本演示突出“与 AI 共生”不是让 AI 接触认证秘密，而是将智能体验放在**解释、排序和引导**上。当前参赛版本以可离线运行的本地安全画像、场景策略和风险规则提供稳定体验；未来如增加联网模型能力，也只能处理用户主动同意发送的脱敏摘要，且默认关闭。

| 演示重点 | 已实现能力 | 向评审传达的价值 |
|---|---|---|
| 本地优先 | TOTP 本地计算、加密备份、本地密码生成 | 高敏感认证数据不依赖第三方模型或服务器。 |
| 智能引导 | 安全建议卡与安全共生计划 | 用户无需理解复杂术语，也能知道今天优先处理什么。 |
| 可解释决策 | 离线可疑登录检查 | 每个风险提示都展示触发依据和官方渠道核验步骤。 |
| 可操作闭环 | 密码账本筛选、生成器策略、备份恢复向导 | 建议不止停留在提示，而是可以直接进入对应操作。 |

## 二、建议 90 秒演示脚本

### 0–15 秒：一句话定位

打开 OTP 首页并展示“智能安全建议”卡。讲解词可以是：

> “小产品实验室 OTP 不把验证码和密码交给 AI。它在本地汇总安全状态，把用户真正需要做的安全操作按优先级讲清楚。”

此时点击“查看安全行动计划”。

### 15–35 秒：展示安全共生计划

展示计划中的“备份验证码”“处理重复密码”“升级较弱密码”等任务。重点说明任务只使用验证码数量、弱密码数量、重复密码数量和备份状态等聚合信息；页面不会展示或上传密码、TOTP 密钥、账号名或备份口令。

点击“查看重复密码”或“查看较弱密码”，展示密码账本自动带入的筛选结果，再返回计划页。

### 35–52 秒：展示本地密码策略助手

进入密码生成器，在“日常账号”“重要账号”“需要手抄”“临时一次性”之间切换。演示“重要账号”自动建议 20 位随机密码，“需要手抄”自动排除易混淆字符。讲解时强调：

> “策略只根据用户主动选择的场景调整参数，密码仍由设备本地随机数生成。”

### 52–70 秒：展示离线可疑登录检查

进入“实用工具 → 可疑登录检查”，载入示例消息。页面会识别紧急催促、域名与品牌不一致、IP 地址登录、短链接、索要验证码或远程控制等信号，并给出低、中、高风险与原因。

重点展示页面中的三项承诺：**不联网、不上传、不保存**。如用户粘贴了密码、TOTP 配置链接、验证码、恢复码或备份口令，检查会停止并提醒先删除敏感字段。

### 70–90 秒：完成备份闭环

进入“数据管理 → 微信导入导出”，展示两个明确操作：“导出至微信”与“从微信导入”。说明 .bak 文件会在设备本地加密后再通过微信发送；换机时从微信选择同一文件，使用相同备份口令恢复。恢复采用合并语义，不会让较旧备份覆盖本地更新内容。本页不会选择或管理手机文件夹，也不提供本地自动备份。

用一句收尾：

> “从识别风险到完成保护，每一步都可解释、可控制，并且秘密始终留在用户手里。”

## 三、提审说明建议

提审描述应避免把本地规则描述成“联网鉴定”或“安全保证”。推荐表述如下：

> 小产品实验室 OTP 提供本地 TOTP 验证码管理、密码账本、随机密码生成、加密备份和离线可疑登录检查。离线检查仅根据用户主动输入的非敏感链接或消息文本进行本地规则分析，不联网、不上传、不保存输入内容；它会提示可观察的风险信号与官方渠道核验步骤，不对任何链接作安全性保证。

| 数据类别 | 处理位置 | 是否发送到网络 |
|---|---|---|
| TOTP 密钥、二维码原文、验证码 | 本地 | 否 |
| 密码、账号、备注 | 本地 | 否 |
| 备份口令、备份文件、WebDAV 凭据 | 本地 | 否 |
| 安全画像（数量与状态） | 当前版本本地生成 | 否 |
| 可疑登录检查的文本或链接 | 当前页面内存 | 否 |

## 四、测试与演示前检查

| 检查项 | 期望结果 |
|---|---|
| 首页安全建议 | 有未备份、弱密码或重复密码时，显示优先行动入口。 |
| 密码策略助手 | 四种策略切换后，长度与排除形近字符选项同步变化。 |
| 可疑检查 | 粘贴含 IP 地址链接、短链接或紧急催促时能展示依据；粘贴验证码或 `otpauth://` 时会拦截。 |
| 微信导入导出 | 导出会创建加密 .bak 文件并唤起微信转发；导入会从微信选择 .bak 文件并进入解密合并流程。 |
| 失效路径 | WebDAV 未配置或无法上传时，仍可完成本地加密备份。 |
| 真机隐私 | 确认可疑检查和策略助手没有发起网络请求，且不产生敏感内容日志。 |
