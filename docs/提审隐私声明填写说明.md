# 小产品实验室 OTP｜提审隐私声明填写说明

**适用版本：** 1.1.0  
**更新日期：** 2026-08-27  
**目的：** 使微信公众平台的《用户隐私保护指引》与当前代码实际调用的隐私接口一致，避免发布后接口被限制。

## 一、必须选择的三项信息

在“管理 → 版本管理 → 提交代码审核 → 信息填写页面”的“用户隐私保护指引”中，**不要选择“未采集用户隐私”**。根据代码检测结果，保留并如实填写以下三项；每项均仅由用户主动点击触发。

| 平台检测标识 | 平台中文名称 | 当前功能中的实际用途 | 建议填写的用途文案 |
|---|---|---|---|
| `AlbumWriteOnly` | 相册（仅写入）权限 | 用户点击“下载二维码”后，将当前生成的二维码图片保存到系统相册。应用不读取相册。 | 保存用户主动生成的二维码图片到系统相册。 |
| `Clipboard` | 剪切板 | 用户点击复制验证码、密码、账号或二维码文字时，写入系统剪贴板。应用不主动读取剪贴板。 | 复制用户主动选择的验证码、密码、账号或二维码文字。 |
| `MessageFile` | 选中的文件 | 用户主动从微信聊天中选择加密 `.bak`、CSV 或 Bitwarden 导出文件导入；导出的加密备份可由用户主动发送至微信会话。应用不会自动读取聊天记录或其他文件。 | 导入用户主动选择的备份或密码文件，并导出用户主动创建的加密备份。 |

> 三项都是平台检测到的隐私接口，不应以“未采集用户隐私”提交。它们不是后台上传、广告追踪或读取通讯录；本小程序没有相关行为。

## 二、平台其他字段建议

| 字段 | 建议内容 |
|---|---|
| 信息存储位置 | 验证码、密码与设置仅保存在用户设备的微信本地加密存储中；WebDAV 备份仅在用户主动配置并执行时上传到用户自行提供的服务。 |
| 保存期限 | 本地数据保存至用户主动删除、清除小程序数据或卸载微信为止；回收站项目依用户设置的保留期限自动清除。 |
| 对外提供 | 不主动向任何第三方共享、出售或公开验证码、密码、备份内容或上述接口产生的数据。 |
| 联系方式 | 填写开发者自己的有效邮箱、手机号、QQ 或微信号之一；请勿填写虚构联系方式。 |
| 更新通知方式 | 隐私指引或处理规则变更时，通过小程序内提示或版本更新说明通知用户。 |

## 三、提审操作步骤

1. 在当前截图所在的提审页面，点击隐私指引的编辑入口，取消“未采集用户隐私”。
2. 按上表添加 `AlbumWriteOnly`、`Clipboard` 与 `MessageFile`，并粘贴对应的用途文案。
3. 核对开发者联系方式、保存期限、存储位置与对外提供说明后保存。
4. 返回提交审核页，确认不再提示“相关隐私接口权限将被回收”，再提交审核。

如隐私指引需要审核，以平台页面展示的审核状态为准。对**当前提审版本**的隐私指引修改应在“版本管理 → 提交代码审核”的信息填写页完成；它不会立即改动线上版本，待版本审核通过并发布后才会覆盖现网规则。[1]

## 四、代码与应用内文案同步

小程序“设置 → 隐私协议”已补充三项说明：复制仅写入剪贴板、保存二维码仅写入相册、导入仅读取用户主动从微信聊天中选择的文件。若后续删除“保存二维码”“复制”或“微信文件导入导出”功能，应在下次提审时同步移除相应隐私声明。
